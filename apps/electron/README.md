# `@deepseek-ai/dsh-desktop`

English | [中文](README.zh.md)

The Electron desktop shell: the main process boots the harness host composition (`dsh-base` bundle + the desktop patch — the web rows minus the webserver-dependent ones) in-process, serves the built web frontend over the `dsh://` custom protocol (dist, boot manifest, plugin bundles), bridges the web client's API calls over IPC, and opens a BrowserWindow. The renderer is the unmodified web client from [`apps/web`](../web/README.md), mounted through `AppWebEntry` with `contextIsolation` and `sandbox` on.

The desktop application follows the design in the [GUI layering note](../../.agents/notes/implemented/architecture/2026-07-19-gui-layering-and-rpc-protocol.md): the web client packages are reused verbatim, and only the carrier changes. The IPC carrier (`M1`) is in place: the preload exposes a narrow `window.__dshBridge`; unary/respond calls ride `ipcRenderer.invoke` to the main process, which dispatches through the exact shared fetch handler the browser carrier bridges onto its HTTP route (privileged-method fence included); the mux and host event streams are pushed to the renderer by the main process. The native desktop capabilities (`M2`) are in place: the directory picker is the Electron dialog backend ([`dsh-host-directory-picker-electron`](../../packages/host/directory-picker-electron/README.md)) with the shared native-interaction client surface, and the window chrome (application menu, tray with close-to-tray) lives in [`src/window.ts`](src/window.ts). `host.openPath` and `settings.openDocument` run through the Host's existing platform openers, which work unchanged in the main process. The `webServer` service is deliberately absent from the desktop composition; [`dsh-client-connection`](../../packages/client/connection/README.md) and [`dsh-client-modules`](../../packages/client/modules/README.md) mount without it and expose their graph/dispatch faces for the shell to serve itself.

## Development

```sh
# at the repository root (required once after a fresh clone):
pnpm run build
# in the apps/electron directory:
pnpm run dev
```

The window opens at `dsh://app/index.html`. With a `DEEPSEEK_API_KEY` configured the real host API flows over IPC; appending `?fixture` still renders the full UI keyless through the fixture carrier. The `dsh://` handler lives in [`src/protocol.ts`](src/protocol.ts) as a pure fetch function; the IPC bridge lives in [`src/ipc-bridge.ts`](src/ipc-bridge.ts) with injected electron surfaces so both are unit-testable. The host boot smoke in [`tests/boot.host.spec.ts`](tests/boot.host.spec.ts) boots the real base + desktop composition and asserts `clientModules` is present, `webServer` is absent, and a real `session.list` envelope dispatches through the IPC handler.

## Packaging (M3)

```sh
# in the apps/electron directory:
pnpm run dist:dir            # unpacked app directory (fast packaging check)
pnpm run dist                # installers: NSIS (win) / DMG (mac) / AppImage+deb (linux)
```

`electron-builder.yml` owns the targets: NSIS for Windows, DMG for macOS (arm64 + x64), AppImage + deb for Linux. The built web frontend ships through the `@deepseek-ai/dsh-web-frontend` dependency; native modules (the Loader's bare-specifier helper, landlock-run, node-pty) are unpacked from asar. The icon assets (`resources/icon.png`, `tray.png`) are generated by `scripts/generate-icons.mjs` (placeholder artwork until a designer ships the real brand assets).

## First build on Windows or macOS

Fresh machine, from the top: install [Node.js](https://nodejs.org) 22.19+ or 24.x, enable pnpm 11.7.0 (`corepack enable`, or `npm install -g pnpm@11.7.0`), install git, then:

```sh
git clone git@github.com:showlovetommy/deepseek-harness.git
cd deepseek-harness
pnpm install      # downloads the Electron binary (~100 MB) on first run
pnpm run build    # at the repository root: compiles every package + the web frontend + this app
```

`pnpm install` downloads Electron; for `pnpm run dist`, electron-builder also fetches its platform toolchains (NSIS on Windows). If GitHub is slow or unreachable, mirror them once per shell: `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` and `ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/` (PowerShell: `$env:ELECTRON_MIRROR="..."`).

Open the app in development with `pnpm run dev` (in `apps/electron`), or package it:

- Windows — `pnpm run dist:dir` → `dist/win-unpacked/dsh-desktop.exe` (double-click to run); `pnpm run dist` → `dist/DeepSeek Harness-Setup-0.1.0-rc.5.exe` (NSIS installer).
- macOS — `pnpm run dist:dir` → `dist/mac-arm64/dsh-desktop.app` (Apple Silicon) or `dist/mac/dsh-desktop.app` (Intel); `pnpm run dist` → `dist/DeepSeek Harness-0.1.0-rc.5-<arch>.dmg`. The config declares both arches, so pass one to build only the local one: `pnpm run dist -- --arm64` (or `--x64`).

A freshly built app is unsigned: Windows SmartScreen may ask for confirmation (More info → Run anyway), and macOS Gatekeeper may refuse the first double-click — right-click the app and choose Open, or clear the quarantine flag with `xattr -dr com.apple.quarantine "DeepSeek Harness.app"`.

## Model Experience

None, as the shell reuses the web client verbatim; the model-visible surface context is owned by the composed web rows (which this desktop patch restates).

#### KV Cache effect

None; this package neither assembles nor sends a provider request.

## Known Limitations and Deferred Work

- **The icon assets are generated placeholders** — `resources/icon.png`/`tray.png` come from `scripts/generate-icons.mjs` (a simple dark rounded square with a chevron); real brand artwork replaces them.
- **The desktop patch restates web rows** — it derives from the web-app bundle patch minus the webserver rows; a change to the web roster must be mirrored here (or the derivation automated).
- **IPC unary has no mid-flight abort** — `ipcRenderer.invoke` cannot cancel the main-process dispatch; caller-side timeouts still reject the renderer promise, and the host handler's result is discarded. A streaming/cancelable IPC path is deferred until a consumer needs it.
- **Electron's bundled Node version must satisfy the repository engines** (`^22.19.0 || >=24.0.0`); verify the chosen Electron line before relying on Node-only APIs.
